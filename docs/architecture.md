# ResiliNER Architecture

## Frontend

The frontend contains six command-center tabs:

1. GIS Map Center
2. AI Risk Simulator
3. Geo Field Reports
4. Emergency Triage
5. Alert Broadcast
6. Risk Analytics

## Backend

The backend exposes JSON API endpoints for system health and landslide risk zones. It can be expanded with sensor ingestion, report verification, alert dispatch, and triage services.
